# amlin.ai

Source for [amlin.ai](https://amlin.ai/), the website for Amlin, a Mac app for AI meeting notes, system-wide dictation, and a to-do list that fills itself. No bot joins your calls and meeting audio is never stored.

Static HTML served by GitHub Pages. Pages worth reading:
